# Tetris Game

A JavaFX-based Tetris game developed as part of the 7010ICT project.

## Features

- Classic Tetris gameplay
- Seven Tetromino pieces
- Piece movement and rotation
- Automatic downward movement
- Hard drop functionality
- Collision detection
- Piece locking
- Line clearing
- Score tracking
- Level progression
- Increasing game speed
- Pause and resume functionality
- Game-over detection
- Restart functionality

## Technologies Used

- Java
- JavaFX
- Maven
- IntelliJ IDEA
- Git and GitHub

## Controls
The following keyboard controls are used to play the game:

- Left Arrow - Move piece left
- Right Arrow - Move piece right
- Down Arrow - Move piece down
- Up Arrow - Rotate piece
- Space - Hard drop
- P - Pause/Resume
- R - Restart game

## Project Structure

The main source code is located in:

`src/main/java/org/example`

The project contains classes responsible for the game board, Tetromino pieces, movement, positioning, and the main JavaFX application.

## Running the Project

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Allow Maven to load the project dependencies.
4. Run `TetrisApplication`.
5. The Tetris game window will open and the game can be played using the keyboard controls.
